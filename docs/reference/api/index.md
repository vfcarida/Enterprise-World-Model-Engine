# Public API Reference Overview

The **Enterprise World Model Engine (EWM Engine)** public API is structured around decoupled, strictly typed protocols and immutable data structures.

All core primitives adhere to [SemVer 2.0.0 stability guarantees](../../stability-policy.md) and support offline execution without mandatory external cloud APIs or neural network runtimes.

---

## Root Export Surface (`ewm_engine`)

The root `ewm_engine` module exposes canonical entry points and contracts for quick-start workflows:

::: ewm_engine
    options:
      show_root_heading: true
      show_source: false
      members:
        - World
        - WorldState
        - Entity
        - Relationship
        - Resource
        - Action
        - Intervention
        - Scenario
        - SimulationEngine
        - compare_scenarios
