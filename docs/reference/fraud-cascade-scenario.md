## 5. Four-Layer Cascade Equations

### Layer 1 — Direct Authorization Transition (`BUSINESS_RULE_MECHANISM`)

Given active customers $C_{\text{act}, t}$, queued retries $R_{\text{retry}, t}$, and runtime threshold $\tau_t \in [0.10, 0.95]$:

$$p_{\text{catch}}(\tau_t) = \text{clip}\!\left(1.0 - k_{\text{catch}}\, \tau_t^2,\; 0.02,\; 0.995\right), \qquad p_{\text{FP}}(\tau_t) = \text{clip}\!\left(\alpha_{\text{FP}}\, \exp(-\beta_{\text{FP}}\, \tau_t),\; 0.001,\; 0.85\right)$$

- Caught fraud: $D_{\text{fraud}, t} = V_{\text{fraud}, t}\, p_{\text{catch}}(\tau_t)$
- Missed fraud: $F_{\text{missed}, t} = V_{\text{fraud}, t} - D_{\text{fraud}, t}$
- Raw false-positive declines: $D_{\text{FP, raw}, t} = V_{\text{legit}, t}\, p_{\text{FP}}(\tau_t)$

### Layer 2 — Triggered Fraud Workflow (`BUSINESS_RULE_MECHANISM`)

When `auto_step_up_sms` is enabled in $K_t$, a fraction $\rho_{\text{sms}} = 0.65$ of raw false-positive declines are rescued via automated SMS challenge:

$$D_{\text{rescued}, t} = \mathbb{I}(\text{SMS enabled})\, \rho_{\text{sms}}\, D_{\text{FP, raw}, t}, \qquad D_{\text{FP, net}, t} = D_{\text{FP, raw}, t} - D_{\text{rescued}, t}$$

Unrescued false-positive declines trigger automated precautionary account locks and dispute cases:

$$L_{\text{locks}, t} = \rho_{\text{lock}}\, D_{\text{FP, net}, t} = 0.45\, D_{\text{FP, net}, t}$$

### Layer 3 — Secondary Customer Behavioral Reactions (`EXPERIMENTALLY_SUPPORTED`)

Customers experiencing net false-positive declines $D_{\text{FP, net}, t}$ and account locks $L_{\text{locks}, t}$ react across three channels:
- **Next-Step Payment Retries:** $R_{\text{retry}, t+1} = \gamma_{\text{retry}}\, D_{\text{FP, net}, t} = 0.35\, D_{\text{FP, net}, t}$
- **Alternative Payment-Rail Switches:** $S_{\text{switch}, t} = \gamma_{\text{switch}}\, D_{\text{FP, net}, t} = 0.20\, D_{\text{FP, net}, t}$
- **Inbound Contact-Center Call Arrivals:**
  $$I_{\text{calls}, t} = r_{\text{routine}}\, C_{\text{act}, t} + \gamma_{\text{call, FP}}\, D_{\text{FP, net}, t} + \gamma_{\text{call, lock}}\, L_{\text{locks}, t} + 0.12\, D_{\text{dispute}, t}$$

### Layer 4 — Call-Center Queueing, Wait Times, SLA & Conservation (`KNOWN_FUNCTIONAL`)

Given staffed agents $N_{\text{agents}, t} \in [10, 120]$ with service capacity $\mu_{\text{cap}, t} = 8.0\, N_{\text{agents}, t}$ and total queue demand $D_{\text{queue}, t} = Q_t + I_{\text{calls}, t}$:
- **Handled Calls:** $H_t = \min(D_{\text{queue}, t},\; \mu_{\text{cap}, t})$
- **Unmet Demand & Abandonment:** $U_t = D_{\text{queue}, t} - H_t$, $A_{\text{aban}, t} = 0.25\, U_t$, $Q_{t+1} = U_t - A_{\text{aban}, t}$
- **Queue Flow Conservation Identity:** $D_{\text{queue}, t} = H_t + A_{\text{aban}, t} + Q_{t+1}$
- **Congestion Wait Time (Seconds):**
  $$\rho_{\text{util}, t} = \frac{D_{\text{queue}, t}}{\max(1,\; \mu_{\text{cap}, t})}, \qquad W_{\text{sec}, t} = w_0 + \kappa_{\text{wait}}\, \rho_{\text{util}, t}^2 = 25.0 + 115.0\, \rho_{\text{util}, t}^2$$
- **Latent Churn Propensity & Cohort Conservation:**
  $$\psi_t = \text{clip}\!\left(0.65\, \psi_{t-1} + 0.35\, \psi_0 + 0.08 \frac{D_{\text{FP, net}, t}}{\max(1, V_{\text{legit}, t})} + 0.04 \max\!\left(0, \frac{W_{\text{sec}, t} - W_{\text{SLA}}}{W_{\text{SLA}}}\right) + 0.03 \frac{A_{\text{aban}, t}}{\max(1, D_{\text{queue}, t})},\; 0.002,\; 0.35\right)$$
  $$\Delta C_{\text{churn}, t} = \min(C_{\text{act}, t},\; C_{\text{act}, t}\, \psi_t), \qquad C_{\text{act}, t+1} + C_{\text{churn}, t+1} = N_0 = 10{,}000.0$$

## 6. Hard Conservation & Capacity Invariants ($\Pi_{\mathcal{C}}$)

`project_cascade_state_to_feasible()` enforces three hard operational invariants on every step and across arbitrary residual perturbations:

1. **Customer Cohort Conservation:** `active_customers + churned_customers == 10,000.0` (verified to max floating-point residual $7.28 \times 10^{-12} \le 10^{-9}$) with non-negativity ($C_{\text{act}, t} \ge 0, C_{\text{churn}, t} \ge 0$).
2. **Contact-Center Queue Flow Conservation:** `total_queue_demand == handled_calls + abandoned_calls + ending_call_backlog` (max residual `0.0`) with `0.0 <= call_backlog <= 5000.0`.
3. **Agent Staffing Capacity Bounds:** `10.0 <= staffed_agents <= 120.0`.

Any out-of-bounds raw residual proposal is projected back onto the feasible set $\mathcal{C}$ and logged in a `ResidualFeasibilityRecord` (`is_feasible`, `policy=InfeasibleResidualPolicy.PROJECT`, `raw_deltas`, `applied_deltas`, `l2_projection_distance`, `violations`).
