Implement World Model Interchange Format (WMIF), standalone fingerprint-exact conformance suite, and WSL authoring tooling (T08, ADR-051): self-describing PKZIP container format (.wmif) modeled on FMI 3.0 with SBML-style Levels and Packages (Level 1 core, optional PkgCausal, PkgCosim, PkgDecisions, PkgStochastic) and fail-closed requirement gates; unified versioned JSON Schema Draft 2020-12 and OpenAPI 3.1 specification for WorldSpec and WSLDocument validating HTTP/MCP payloads and standalone files; streaming AsyncAPI 3.0 document for long-running Monte Carlo simulation jobs; MLCommons Croissant 1.0 JSON-LD dataset manifests (arXiv:2403.19546, NeurIPS 2024 D&B) emitted per simulation output for ML dataset discoverability; Reference Worlds (ref_seed_trivial, ref_closed_form_stochastic, ref_constraint_stress) with golden bit-exact SHA-256 fingerprints; standalone MIT-licensed EWM Conformance Suite modeled on the JSON Schema Test Suite with latest/, optional/, and proposals/ categories and automated negative mutation testing; and safe declarative WSL authoring tooling including a Lark LALR(1) grammar parser without code execution, a pygls Language Server (LSP) with live diagnostics, a thin VS Code client extension, and a Modelica-grade written specification (docs/specs/wsl-v2.md).
